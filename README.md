# Joe Devon

Founder of [A11y Audits](https://a11yaudits.com), creator of Global Accessibility Awareness Day, and immediate past chair of the [GAAD Foundation](https://gaad.foundation). I co-host the Accessibility and Gen. AI Podcast and build AI tools that help developers ship accessible software.

Most of what I work on now comes down to one idea: accessibility belongs in the code while it is being written, not in an audit after the fact.

## Current projects

- **[AIMAC](https://github.com/GAAD-Foundation/AIMAC)**, the AI Model Accessibility Checker. It has language models generate web pages, runs axe-core on the results, and scores each model on serious and critical violations. Results at [aimac.ai](https://aimac.ai). A GAAD Foundation project, MIT licensed.
- **[VisionScribe](https://github.com/joedevon/visionscribe)**, a skill for Claude and Codex that writes alt text and image descriptions using the best advice of accessibility experts. Share an image, say where it will be used, and get text ready to paste into code, a CMS, a blog post or a social media post.

## GAAD

Global Accessibility Awareness Day started with [a blog post I wrote in November 2011](https://mysqltalk.wordpress.com/2011/11/27/challenge-accessibility-know-how-needs-to-go-mainstream-with-developers-now/), asking why accessibility know-how had not reached mainstream developers. Jennison Asuncion read it, and together we launched the first GAAD in May 2012. It now happens every third Thursday of May. On GAAD's tenth anniversary we started the GAAD Foundation, and in 2025 [GitHub took the GAAD Pledge](https://github.blog/open-source/social-impact/our-pledge-to-help-improve-the-accessibility-of-open-source-software-at-scale/), committing to improve the accessibility of open source at scale.
